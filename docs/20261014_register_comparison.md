## bandwidth·압축·write에 대한 현재 판단

10→40→160은 segment150 대비 강한 압축·중간 용량·비슷한 크기의 state를 나누는 첫 탐색으로 적절하다. register 하나를 token 하나와 대응시키거나 M≈segment를 최적점으로 보지는 않는다. state는 여러 segment의 정보를 누적하며 K3은 gradient 범위이지 저장 가능 문맥의 상한이 아니다.

- M10은 gate가 모두1이고 cosine이 거의1이지만10개 슬롯 모두 초기화 평균 효과가 양수다. 유용한 메모리 전달은 존재하며 방향 유사성만으로 모든 슬롯이 같은 기능이라고 단정하지 않는다.
- M40은33개 열린/7개 닫힌 write 경로로 거의 고정돼 있다. 그러나40개 슬롯 모두 평균 초기화 피해가 양수이고 닫힌 slot10도 기여 상위권이다. 열린 슬롯 수만 실효 bandwidth로 세지 않는다.
- M160은 가변적인 write 부분과 고정 포화 부분이 공존한다. 양/음/작은 평균 slot 효과는140/19/1개(절대값1e−6 기준)다. 낮은 write를 미활용으로, 큰 M을 무압축으로 단정하지 않는다. 전체 품질 개선과 추가 비용을 함께 평가한다.

개별 슬롯의 효과는 작고 합산되지 않는다. 전체 reset 피해는 단일 슬롯 delta 합보다 크며 중복 표현·상호작용·joint reset의 비선형 효과가 가능하다. 슬롯별 효과의 정확한 정의와 gate 그룹별 수치는 상세 보고서에 둔다.

## 학습 전환과 기억의 지속

세 용량 모두 초기 state가 해로운 구간 이후3k→4k 평가 사이에 write 동작·품질·reset 효과가 함께 개선됐다. M160은6k→7k에 평균 write가 줄면서 품질과 실제 relative update가 개선돼 큰 평균 write 하나로 학습 성공을 설명할 수 없다. 최종 checkpoint의 사후 분석만으로 초기 학습 전환의 원인을 확인하지 않는다.

swap 이후 lag0→lag3 ΔNLL은 M10 0.422916→0.009960, M40 0.524916→0.017808, M160 0.294080→0.011249다. M40의 절대 영향은 가장 크지만 초기 영향 대비 lag3 잔여 비율은 M160이 조금 더 크다. 민감도와 감쇠 비율을 구분하며 정확한 기억 수명으로 해석하지 않는다.
